실무에서 해온 일

게임 플랫폼 웹 개발·운영을 맡으며 API 연동, 배포, 인증, 데이터 분석 환경을 다뤘습니다. 아래는 재직 중 수행한 업무이며, 위 개인 제작 데모와 구분됩니다.

01 / DEPLOYMENT & INFRA

배포와 서버 운영

  • Jenkins 파이프라인과 Groovy 스크립트로 배포를 자동화해 소요 시간을 약 1시간에서 20분으로 줄였습니다.
  • 클로저스 국내 서비스 오픈을 위한 Ncloud 웹 서버 설정, API·DB 연동과 테스트를 진행했습니다.
  • Azure MariaDB에서 MySQL로 데이터를 이관하고, 배포 중 DB 연결 실패를 해결하기 위해 Custom DataSource를 구현했습니다.
02 / AUTHENTICATION

로그인과 보안

  • 웹 로그인에 Google OTP 인증 단계를 개발하고, 대만·일본 서비스의 보안이 필요한 메뉴에도 적용했습니다.
  • 게임별 로그인 흐름을 정리하고 서비스별 접근·인증 절차를 개선했습니다.
03 / WEB & API

웹과 외부 API

  • 로스트아크 대만 홈페이지 ↗ 개발에 참여해 개발사 API 연동, 계정 차단 기능과 OTP 인증을 구현했습니다.
  • 고검기담·소호강호 홈페이지에서 쿠폰 및 아이템 전송 API를 개발했습니다.
  • 클로저스 국내 홈페이지 ↗의 로그인·커뮤니티 게시판과 1:1 문의 기능을 개발했습니다.
04 / DATA & LOGS

데이터와 로그 분석

  • Fluentd와 Azure Storage로 로그를 모으고, Azure Log Analytics에서 결제·쿠폰 로그를 분석할 수 있게 했습니다.
  • Metabase를 연동해 비개발자와 데이터 분석팀이 유저 지표를 조회할 수 있도록 했습니다.
